02 · Fixture list

The 24-hour schedule (UTC)

Four EventBridge rules drive all the background work. The orange beads are the 30-minute ingest; the big dots are the nightly chain. The hand shows the current UTC time.

Chained by clock, not by events. The analyzers assume the ingests finished because they run hours later. If Sunday's history ingest fails, the 04:00 and 04:30 analyzers still run on last week's history, and only the ingest's own alarm tells you. Step Functions would make the dependency explicit; that's your open issue #40. EventBridge Scheduler is also now AWS's preferred home for cron jobs (time zones, one-off schedules, per-target retry policy).

05 · Tactics

The xP model

Expected points per player per gameweek, summed from nine independent components. The v1 model was retired in PR #127; what runs now is v2, with coefficients fitted offline on your laptop and shipped inside the Lambda layer. Click a component.

factor = 1 + home_advantage·sign + opp_strength_w × (opp_strength − 0.5), where opp_strength = (fpl_difficulty − 1) / 4. p_any and p60 gate everything; FPL's chance_of_playing = 100 is treated as "no info", the same as null.
